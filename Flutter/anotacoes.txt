        - Quando usa Row dentro de Column, geralmente o conteúdo fica
            colado do lado esquerdo. Para resolver isso, usar:
            
            Row(
                mainAxisAlingment: MainAxisAlingment.center
                children: ...
            )

            MainAxisAlingment.center: centraliza o conteúdo
            MainAxisAlingment.spaceAround: coloca espaço antes e depois dos elementos
            MainAxisAlingment.spaceBetween: deixa todos com espaçamento responsivo 
                (pontas vão para as bordas, meio fica centralizado)

            MainAxisAlingment.spaceEvenly: coloca exatamente o mesmo espaçamento entre 
                os elementos, sem socar o depois + antes do outro elemento
